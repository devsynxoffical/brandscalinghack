1. Technical SEO & Pre-Rendering Overhaul

Root Cause of the "Splash Screen" Text Flash

When opening the live site, visitors saw a split-second black screen with raw white text ("The Performance Marketing Agency for DTC Ecommerce Brands Ready to Scale..."). This occurred because scripts/prerender.cjs was injecting raw semantic HTML directly into <div id="root"> without styling containment until the ~985 KB JavaScript bundle downloaded and mounted.

The Fix:

  • Replaced raw text inside <div id="root"> with an ultra-fast inline branded loader (Brand Scaling logo + smooth glowing orange spinner on #07090e canvas).
  • Wrapped semantic headings, paragraphs, and links into an accessible screen-reader/crawler container (position: absolute; width: 1px; height: 1px; overflow: hidden; clip: rect(0, 0, 0, 0);).
  • Injected an official <noscript> block for non-JS web crawlers.
  • Added missing spoke routes (/blog/performance-marketing-agency and /blog/what-is-roas) to the static build pipeline.
