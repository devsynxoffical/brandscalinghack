Why links matter here: the technical audit (docs/technical-audit-2026-11-23.md) found no technical block. Google crawls and ranks a new site with no links slowly. Links from relevant sites are the main missing signal for crawl demand and for moving agency pages from position 40 or worse into the top 10.

## Rules (what we will and will not do)

- **Yes:** links we earn or that come from real relationships: directory profiles of real agency listings, partners, clients, podcasts, journalists, communities, and genuinely useful assets (calculators, original data from our case studies).
- **No:**
  - buying links or paid guest posts with dofollow links;
  - private blog networks;
  - link exchanges at scale;
  - comment or forum spam;
  - mass low-quality directories;
  - automated link services;
  - sitewide links from our other websites only to pass authority.

  These break Google's spam policies and can get the site demoted.
- **Anchor text:** mostly the brand ("Brand Scaling", "Brand Scaling Hacks"), the founder's name and plain URLs. Only a small share should be keyword anchors such as "Meta ads agency". Never use the same keyword anchor everywhere.
- **Same details everywhere:** use one name, address, email and description on every profile, so Google can connect them (see the profile kit below).

## How we track it

- Bing link counts (GetLinkCounts) in every 12-hour check. Bing is free and shows new links within days.
- Search Console, Links report ("Top linking sites"): owner checks monthly. The API does not expose it.
- A link log, to add when the first links go live: date, linking site, page linked, anchor, dofollow or nofollow, how it was earned.
- Effect on rankings: the keyword-plan table and crawl counts already in docs/seo-tracking.md.
